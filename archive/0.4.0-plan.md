# 0.4.0 — visual test scenes

The scene selector loads reproducible maps together with rule settings, and reset replays the current map without discarding later tuning. Keep the original three-seed startup as the default.

Scenes cover the original seeds, a three-color Voronoi junction, a two-color contact with conversion, a directed absorption front with a third-color tracer, a high-pressure isolated bubble, and three growing colonies with depletion. Static scenes disable production; the colony scene enables bounded territory growth. Layouts are generated directly in the field and use no random state.

The selector applies the selected profile, resets the simulation and synchronizes controls. Reset regenerates only the selected layout, preserving user-edited rules. Profile arrays are copied so runtime edits cannot mutate preset definitions.

Validation: syntax checks, DOM smoke covering all scene selections and reset, simulation checks. Manual pass: select each scene, check its initial geometry and rule labels; run/pause, reset after tuning a rule, then change scenes and verify the new profile is applied.
