decisions:
	permission bit = pair index (1<<p), never the species mask: `mm & PAIR_MASK[p]` read every mask as "all on" and made every pair a wall/no-wall at once.
	a permitted pair with rate 0 is on and acts as a wall: treating it as unmixable turned the receiving side into a vacuum and suction pulled the donor across a disabled pair.
	a forbidden direction is a hard valve in the acceleration (both blocked = no flux, one blocked = that sign cleared); smooth `k*(1-g)` permeability only slowed penetration and never stopped it.
	per-pair reaction is symmetric per pair (`min(a,b)`), not a sorted-channel scheme: sorted roles made RB/GB react through the RG rate, so one enabled pair drained two unrelated colors.

pitfalls: unique DOM ids across widget kinds (checkbox vs slider both wanted `mix-rg`); a range `input` handler that reads a stale `def` reads `undefined` (findings).
next step: per-pair absorb asymmetry (a pair that consumes only one side) or pair-level scoring in `#stats`.
