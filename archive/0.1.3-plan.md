# plan 0.1.3 — hover probe and substepped diffusion

Zero-depletion diffusion converged to uniform 255 only on a minutes timescale, which read as a frozen
"stable gradient". This plan makes the motion visible (hover probe) and compresses the timescale
(substepped rounds for rates above the explicit-stability limit), without touching game rules.

## hover probe

- `input.js` reports the hovered cell on every `pointermove` (also while not painting) and hides on
  `pointerleave`.
- `ui.js` `uiProbe(x, y, px, py)` fills a fixed-position tooltip next to the cursor: cell coordinates
  plus `R/G/B` at 0.1 resolution, colored by channel. One decimal keeps the asymptotic creep near 255
  visible that integer rendering hides. Works while paused; costs nothing in the frame loop.

## substepped diffusion

- Explicit 4-neighbour spread is stable only while the per-neighbour share stays <= 255/1024 per
  update, so `settings.diffuse` now ranges 0..1020 and `simStep` splits rates above `MAXV` into
  `ceil(rate / MAXV)` rounds of `rate / rounds` each.
- Cross rates scale by `1 / rounds` inside `spreadPass`, so cross-vs-base balance keeps per-step
  semantics; depletion applies once per step (first round); `sourcePass` pins sources and clamps every
  round.
- Rate <= 255 runs exactly one round with scale 1 and stays bit-identical to the single-round path.

## headless probe

`experiments/line_probe.js` paints a 1px line (or point) source and logs `reach` (max source distance
with value >= 1), `high` (distance >= 250), `min`, total and a cross-section at fixed step checkpoints
for rates 128/255/510/1020, plus deplete=1. `experiments/sim_smoke.js` gains `case=rounds_fill` as the
stability/fill regression for the substepped path.

## manual pass list

1. Depletion 0, line of R sources, default rate: hover far cells and watch values climb at 0.1
   resolution — no frozen gradient.
2. Diffusion 1020, line source: the whole map passes 250 within ~30 s at speed 4.
3. Depletion 1, default rate: the front pins at ~7 cells from the line (tax equilibrium) — intended
   rule behavior.
4. Tooltip follows the cursor, shows live rgb while paused, hides when the pointer leaves the canvas.
