# plan 0.1.4 — max color as production cap, brownian neighbour shuffle

Two rule fixes. The `maxColor` slider read as a hard total that killed motion, and flat
low-gradient diffusion was too slow to watch without pushing the rate into substepped rounds.

## max color: limit the source, keep the mass

- The cap no longer rescales the field. It limits **production**: in `sourcePass` a source cell is
  pinned to `min(MAXV, cap - (total - its value))` per channel, so once the channel holds
  `cap = maxColor + territoryCap * count[c]` the sources stop feeding and the stored color keeps
  diffusing. Total mass is conserved (no per-step destruction), which the old whole-field
  `a[i] *= cap / total` violated — the far field (< 1 display unit) decayed geometrically to
  black each step and the map read as "diffusion stopped".
- Existing stock above a lowered cap is never destroyed; the source just starves until the field
  diffuses, reacts or depletes back under the cap.
- `count[c]` must be current when `sourcePass` reads it, so `simPaint`/`simClear` keep the
  ownership count fresh with an O(1) `adjustCount` (one cell's ownership changes, undo + recount)
  instead of a full `countPass`.

## brownian neighbour shuffle

- New `settings.brownian` (0..255, default 0 = off). Before each diffusion round of each channel,
  `brownianPass` randomly swaps nearest cells: even cells propose one random neighbour (xorshift32
  direction roll), odd cells accept exactly one claimer (uniform random pick among claimers, so
  no direction drifts), and every write reads the old buffer into the existing swap buffer, so a
  value moves at most one cell per pass.
- The pass is an exact permutation: mass is conserved bit-for-bit and a uniform field is
  untouched. It runs once per diffusion round, so it scales with the substepped rounds like the
  rate does.
- Why it helps: explicit spread moves only `v * rate / 1024` per neighbour per round, so the flat
  far field creeps. Random swaps add a gradient-independent random walk that mixes the tail
  several times faster (line source, rate 128: far corner ~10 at step 3000 vs ~65 with
  brownian=255).

## UI

- `brownian` slider 0..255 under diffusion, bound by the generic range binder.
- Hint line mentions both rules in one sentence each.
