# 0.3.3 — shareable GUI settings

The address bar automatically stores changed GUI values as `dt.` query parameters. Omit values equal to the selected scene's profile; omit the scene when it is Classic seeds. Array controls use indexed parameters. Preserve unrelated query parameters and the fragment. For file URLs, store parameters after a question mark in the fragment because file origins may reject history updates. Restore the scene profile first, then valid overrides, before seeding the map and synchronizing controls. Ignore malformed, out-of-range and off-step values. Settings links describe a fresh scene, not the current evolving field or painted cells.

Validation: DOM smoke covers default omission, scene-relative overrides, reload and malformed values; simulation checks cover boot changes. Manual pass: open a file URL, tune controls, copy and reopen the address, switch scenes and reset; verify controls, profile and seeded geometry.
