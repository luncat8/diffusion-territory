# 0.2.3 — reaction modes, shared player supply, and pair scoring

Replaces single-law overlap reaction with four switchable per-pair reaction modes, adds an optional
per-player shared injection supply that self-limits source spam emergently, splits reaction logic
into `react.js`, and surfaces per-pair contested area and reaction score in `#stats`.

## reaction modes (`react.js`, `settings.js`)

Active reaction pairs are `Settings.reactMask & Gas.liveMask(Settings)`: a pair reacts only while
its mixing channel is open (`mixMask` bit set and `mixRate[p] > 0`), so 1-cell unmixable VOF seams
never erode when reaction boxes stay checked.

Each pair `p` (`0 = RG`, `1 = RB`, `2 = GB`) uses `q = (reactRate[p] / 100)^2` with a 1-quantum
minimum floor so trace overlap clears to zero instead of freezing below `1 / q`. `Settings.reactMode`
selects one of four laws (`REACT_MODES`):

- `0 = mutual` (default) — symmetric attrition: both channels lose `lo * q` (`1:1` Lanchester linear).
  Borders drain both sides in proportion to overlap area and front length.
- `1 = majority` — emergent local dominance: minority loses `m = lo * q`, majority loses
  `m * (lo / hi)` (`1:1` at exact tie, steep discount when concentrated). Symmetric across players,
  asymmetric by local pressure.
- `2 = convert` — mass-conserving cultural assimilation: when `a != b`, minority transfers
  `lo * q * |a - b| / (a + b)` quanta directly into majority. Total `R + G + B` mass is exact to
  the quantum; gains scale separately against `Field.cap[c]` and `Field.budget[c]` so caps and
  `maxMass` never overshoot and a capped channel never blocks another pair in the same cell.
- `3 = absorb` — directed one-sided consumption: `Settings.reactDir[p]` (`0` = first consumes
  second, `1` = second consumes first; default `[0, 1, 0]` = cyclic `R>G, B>R, G>B`) removes
  `lo * q` from the prey channel and `0` from the predator channel.

## shared player supply (`source.js`, `settings.js`)

- `Settings.playerFlow` (`0..2000 /f`, default `0` = off) caps total injection per player per frame
  across all of that player's active source cells, intersected with remaining `budget[p] - total[p]`.
- `Source.inject` sums per-player source headroom demand first, then distributes limited room via
  running rational apportionment (exact remainder on the final source). Sources share supply evenly
  without scanline bias and conserve exact integer budgets.
- With `playerFlow > 0`, source count forms an emergent optimum: too few sources choke on the `255`
  cell ceiling; too many sources dilute per-source flow and drop frontier pressure.

## pair metrics and panel (`field.js`, `view.js`, `controls.js`, `style.css`)

- `field.js` owns `PAIR_A`, `PAIR_B`, `PAIR_NAMES`, `Field.srcCount[3]`, `Field.pairCells[3]`
  (cells where both pair channels are `>= 1` display unit), `Field.pairBurn[3]` (cumulative reacted
  or converted mass per pair), and `Field.pairNet[3]` (cumulative net mass advantage `A - B`).
- `REACTION` panel section adds four mode buttons (`#mode-mutual/majority/convert/absorb`); in
  `absorb` mode each pair row reveals a direction toggle (`#dir-rg/rb/gb`, `R>G` ↔ `G>R`).
- `Player supply` slider (`#ctrl-playerFlow`) sits above `Total color limit`. Pair rate outputs show `%`.
- `#stats` displays live `mix` and `react` pairs (directed in `absorb` mode) plus active mode name,
  per-player `cells / src / cap / mass`, and a `pairs` line with `RG`, `RB`, `GB` overlap cells and
  symmetric burn (`-N`) or net leader (`R+N`).

## validation

- `node experiments/checks.js` — 41 checks: carried 0.2.2 suite plus zero-rate low-density wall,
  unmixable seam protection, sub-quantum completion, `majority` ratio and tie symmetry, `convert`
  quantum-exact mass conservation and cap compliance, `absorb` direction flip and cyclic 3-way
  symmetry, `pairCells` count, fair `playerFlow` split, and emergent overspread penalty.
- `node experiments/dom-smoke.js` — 31 checks: 10 scripts, 16 sliders, mode buttons, `absorb`
  direction toggle reveal and flip, `playerFlow` binding, and `#stats` pair formatting.
- `node experiments/gas-bench.js` — `1.37–4.31 ms/frame` at `128×128` across all transport and
  reaction modes.
- `node experiments/snapshot.js` — 10 PNG renders covering unmixable, depletion, single-pair mix,
  and all four reaction modes.

Manual pass: open `index.html`; enable `mixing all` and `reaction all` with reaction around `15–20%`;
click through `mutual`, `majority`, `convert`, and `absorb` (flip `R>G`/`B>R`/`G>B` badges) and
compare borders and the `pairs` line in `#stats`; set `Depletion` to `0.2/f` and `Player supply` to
`400/f`, then compare a player with 3 spaced sources against one with 25 painted sources.
