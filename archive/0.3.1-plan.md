# 0.3.1 — concentration-driven cells

All rules use local concentrations or adjacent edge differences, never target searches or distance fields. Reference concentration is 255; 5% is the fixed control and production threshold. Traces below it remain transported and reactive. Unique concentration maximum above threshold determines territory; ties are contested.

Production modes: dominance (`r > k*(g+b)`), low pigment (`max(0, 3-s)/3`), and thresholded low pigment (also `s<T`), where `s=(r+g+b)/255`. Every mode requires the producing pigment >=5%. Production is multiplied by `max(0,1-r/C)` and bounded by per-cell and shared player budgets. C is the configured ceiling or 255. Painted brushes deposit/erase pigment, not persistent generators. An optional production overlay marks currently eligible cells; it is off by default to keep dense fields readable.

Reaction demand is `lambda*min(a,b)*(clamp(a/255)*clamp(b/255))^n`, lambda in percent per tick, exponent 1 or 2. Defaults: 2%, n=1. Existing mutual, majority, conversion and directed absorption laws use this demand. Fractional demands accumulate per cell/pair/direction; no minimum-quantum consumption or artificial residual floor. Reset clears carries.

Six directional response sliders control attraction/repulsion to rival gradients. On mixing-enabled edges the conservative flux adds `chi * donor * (rivalB-rivalA)/255`, using only adjacent cells. Closed pairs remain barriers. Gas speed zero freezes transport; substeps split the gradient response so its nominal strength is per tick. Existing fixed-point conservative edge transfer and caps bound motion.

Validation: syntax checks, simulation invariants, concentration regressions, DOM smoke. Manual pass: switch production modes and thresholds; paint/erase pigment; inspect eligible source marks and uncontrolled dilute regions; enable RG mixing/reaction and R→G response; compare reaction exponent 1/2 and check gradual front motion; reset while paused and running.
