# 0.2.2 — per-pair mixing and reaction rules

Mixing and reaction become per color pair instead of one global switch. Each of the three pairs
(`RG`, `RB`, `GB`) has its own mix permission, its own mix rate, its own reaction permission, and
its own reaction per-frame amount. The single global switch and the two global sliders are gone.

## pair rules

- Pairs are numbered `0 = RG`, `1 = RB`, `2 = GB`; a pair `p` is the bit `1 << p`, so a pair set is a
  3-bit mask (`all = 7`). Species masks (`3, 5, 6`) appear only in the solver's per-direction tables.
- `Settings.mixMask` (`0..7`) and `Settings.reactMask` (`0..7`) hold the permissions;
  `Settings.mixRate[0..2]` holds each pair's mix conductivity and `Settings.reactRate[0..2]` its
  reaction share, both in display units per frame (`0..100`; defaults `50`/`50`/`50` and `5`/`5`/`5`).
- A pair is on when its bit is set, whatever its rate: rate `0` is a hard wall, not "off". Dragging a
  pair rate above zero sets its bit, so a slider always takes effect immediately; unchecking the bit
  freezes the pair at its current rate.
- Opposite species repulsion and total-pressure push stay on for every pair: the mask decides
  penetration, never push. A disabled pair therefore behaves exactly like unmixable gas.

## transport (`gas.js`)

- Mixing is active while any pair bit is set; with all bits clear the solver stays on the bulk
  unmixable path (shared `ptot`, VOF donor routing, interface sharpening), unchanged from 0.2.1.
- Per-species transport folds a per-direction permeability into the face acceleration instead of
  scaling momentum after damping (the 0.2.1 fix, now per pair): `kf = k * q`,
  `dampf = damp + (0.75 - damp) * (1 - q)`, `q = rate / 100` of the mobile species against the
  receiving cell's species. Empty receivers take `q = 1`, so a pair never slows free flow.
- A direction a species may not enter is a valve in the acceleration: both directions blocked
  clears the face flux, one blocked keeps only the allowed sign. This makes a disabled pair and a
  `rate = 0` pair identical: zero mass crosses, and the pressure of the blocked side still pushes
  back through `dampf` (a vacuum would let suction pull the donor across).

## reaction (`gas.js`)

- A cell reacts pair by pair among the species present: each live pair removes `min(a, b) * share`
  from both of its channels, with `share = (rate / 100)^2` (`5/f` → `0.25 %` per frame). Removal is
  exactly symmetric inside a pair, so a channel only ever loses to a permitted partner.
- Triple overlap draws from the same channel twice; all three pair demands are scaled by one common
  factor when any channel would be overdrawn, so no channel goes negative and the pairs stay
  proportionate.
- Unmixable pairs never overlap in a cell, so with all mix bits clear reaction is a no-op; the
  panel can have reaction checked while the map is a pure wall war, which is the intended default.

## panel (`controls.js`, `style.css`, `view.js`)

- `MIXING` group under `Gas viscosity`: `RG RB GB all` checkboxes (`#mix-rg-on …`, `#mix-all`) and
  `Mix into other color RG/RB/GB` sliders (`#mix-rg/rb/gb`), each row dimmed while its pair is off.
- `REACTION` group after the mixing sliders: the same `RG RB GB all` pattern (`#react-rg-on …`) and
  `Reaction RG/RB/GB` sliders (`#react-rg/rb/gb`). Checkbox ids carry `-on`, slider ids do not,
  because panel ids must be unique across widget kinds.
- `#stats` names the live pairs (`mix rg/rb · react gb`, `mix none`) instead of a global mode.

## validation

- `node experiments/checks.js` — 32 checks: pair permission direction (RG on lets R into G, not G
  into B), per-pair rate ordering, reaction isolation per pair (only enabled pairs remove, amount is
  `rate` per frame from each side, triple overlap symmetric), `rate = 0` acts as a wall, all-off
  separation vs all-on mixing, single-quantum spread with exact mass, plus the carried 0.2.1 checks
  (mass exactness, walls, caps, depletion, visible reactive front, `maxMass`, source purge).
- `node experiments/dom-smoke.js` — 24 checks: boot, 15 sliders, 8 pair checkboxes, group `all`
  toggle, per-pair auto-enable, checkbox accumulate/clear, paint/erase, tooltip, reset, rAF loop.
- `node experiments/gas-bench.js` — `0.98–2.80 ms/frame` at 128×128 (`mix_all_react5` 2.8,
  `mix_rg_only` 1.9, unmix 1.2–1.4).
- `node experiments/snapshot.js` — `pairs_rg_only.png` (R/G interpenetrate into a yellow field while
  B keeps a hard wall) and `pairs_all_react5.png` (three reactive fronts, no map blackout).

Manual pass: open `index.html`; check `RG` only and watch R and G merge while B stays a hard wall;
add `RB` and the R side gains a wall against B only; set `all` and sweep the three `Reaction`
sliders from `0` to `100` to move from a wide glowing overlap to a thin front; set one pair slider to
`0` with its box checked and confirm that pair stops penetrating without freezing the map.
