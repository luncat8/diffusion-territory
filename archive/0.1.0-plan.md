# 0.1.0 — color diffusion territory

Prototype game: 128×128 cells, three players (R, G, B). A player paints source cells; color
injects there, spreads by diffusion and Brownian exchange, is destroyed where two colors meet,
and can be limited by a per-cell ceiling that scales with claimed territory.

Open `index.html` directly (file://), or serve the folder. No build, no modules.

## model

Cell field, 3 channels, fixed point Q12.12 in `Int32Array` (`FP = 12`, 1 display unit = 4096).
Choose 12 bits because: display ceiling 4095 × 4096 = 2^24 fits Int32; the largest flux product
`|Δ| × k` with `k ≤ 64` stays under 2^31; and 1/4096 is far below anything visible, so
quantisation cannot hold a visible gradient (see "why the plain integer version froze").

Per frame, in order (`tick.js`):

1. `analyze` — dominant channel per cell (`dom`), owned cell count, total per channel.
2. `caps` — per-cell ceiling and total budget per player.
3. `inject` — source cells add color.
4. `substeps` (1 or 2) of: Brownian exchange, then diffusion.
5. `react` — mixed cells lose the shared part of the two colors.
6. `deplete` — every cell loses a fixed amount.
7. `pressure` — optional gas equalisation.

## invariants

- Motion (Brownian, diffusion, pressure) never changes the total of a channel.
  Flux is computed once per edge and applied to both ends with opposite sign.
- Sources only add. Reaction and depletion only remove, by rule.
- A ceiling limits inflow and injection, never removes mass that is already in the field.
  A cell above its ceiling therefore still drains, and the field never appears to freeze.

## diffusion

For every horizontal and vertical edge, per channel:

```
d = a - b
f = (d * k + FP/2) >> FP          // k in Q8, 0..64
if f == 0 and d != 0: f = ±1      // one quantum towards the low side
a -= f, b += f
```

`k = round(diffusion% * 64/100)`, minimum 1 whenever the slider is above zero, so the slider
never rounds down to "off". `k ≤ 64` (0.25 per neighbour) is the stability limit of the explicit
4-neighbour update: `v' = v + Σ k(v_j - v)` stays non-negative.

Why the `±1` fallback: with pure rounding, every edge whose flux rounds to zero is a frozen edge,
and a field of such edges is a fixed point — the field stops one step short of flat, forever.
The `±1` transfer is a quantum (1/4096 of a display unit), so it removes the fixed point without
producing visible noise. This is the whole answer to "diffusion stops at ~250 and never reaches 255".

A cell can end a step a few quanta below zero (`k` at the limit, rounding). `Field.settle()`
keeps that debt in place if it is smaller than one display unit and hands anything deeper to the
richest neighbour, so the total stays exact; clamping to zero instead would silently add mass.

Color walls: an edge carries channel `c` into a cell only if that cell is empty or already
dominated by `c`. With "colors block each other" off, inflow is scaled by the
"diffuse into other color" slider and both colors can occupy a cell (which then feeds reaction).

## Brownian exchange

Parity pairing: cells with `(x+y)` even swap with one random 4-neighbour, whole cell (all three
channels). Each cell takes part at most once, so a single pass is a permutation: mass exact, no
second buffer, and no cell can travel further than one cell per pass. Swapping is skipped at
color walls (same rule as diffusion) because a swap would move both colors across the wall.

Brownian mixing cannot equalise on its own: a uniform blob is only relocated, never split.
It accelerates diffusion where a gradient exists and, at 100 %, removes the lattice pattern that
diffusion reinforces.

## ceiling and territory

Slider `capBase` = the per-cell ceiling on a territory of `REF_OWNED = 16` cells, 0 = no limit.
Slider `capTerritory` = how strongly a smaller territory raises the ceiling:

```
growth   = 1 + capTerritory/100 * max(0, REF_OWNED / owned - 1)
cap      = clamp(capBase * growth, 1, 4095)      // display units
budget   = cap * max(owned, 1)                   // total the player may keep
```

`owned` counts cells where the player's channel is strictly the largest. Two owned cells with
`capBase = 50` and `capTerritory = 100` give `growth = 8`, so each cell may hold up to 400 while
the player's total stays 800: spreading thinner is what raises the per-cell share. Injection stops
at the budget and at the cell ceiling; diffusion inflow stops at the ceiling; outflow is never
limited, so a shrinking territory releases mass instead of freezing.

Totals are exact: no code path drops mass to satisfy the ceiling.

## gas pressure (`pressure.js`)

Optional, off by default. For each channel a mean pyramid is built (2×2 sums and counts per
level, up to 1×1), then each cell is moved toward its group mean at every level:

```
m = trunc(t * (groupMean - v) + acc[group]) ; acc[group] = remainder
```

Error feedback inside each group makes the moves sum to zero, so the only residual is a single
quantum and no cell can be pushed negative. Levels are applied finest to coarsest, so the coarsest
level (the whole grid) removes the slow mode immediately: 5 % per level gives 62 frames to 5 %
deviation where local diffusion needs more than 40 000.

Cells dominated by another color are excluded from the pyramid, so a color never equalises into
another player's body — but the pyramid links cells across obstacles, so pressure can carry mass
across a wall of a different player (a gas has no walls). It also ignores the per-cell ceiling;
it never creates or destroys mass. See `gas/notes.md` for measurements.

- `node experiments/checks.js` — mass exactness, zero sliders are no-ops, rate ordering,
  low-gradient motion, ceilings, walls, reaction, depletion, pressure vs walk. 20 checks.
- `node experiments/dom-smoke.js` — boot, 10 sliders, hover tooltip, paint/erase, reset, rAF loop.
- `node experiments/int-stall.js` — 1×128 line: naive 8-bit freezes at frame 1000 (dev 100.8 %,
  half the line empty), shipped kernel keeps moving and is within 0.55 % at 100 000 frames.
- `node experiments/diffusion-line.js` — 2D line spread, mass and deviation per 1000 frames.
- `node gas/bench.js` — equalisation race, see `gas/logs/`.
- `node experiments/snapshot.js` — offline PNG renders in `out/`.

Manual pass: paint three sources, drag to paint a region; watch the tooltip fractions move on a
flat gradient; set diffusion 0 and confirm nothing changes; set cap 60 and confirm cells hold at
the ceiling while the field keeps diffusing; toggle gas pressure and watch the map equalise.
