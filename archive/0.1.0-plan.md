# plan 0.1 — diffusion territory prototype

Cultural influence prototype. Three colors (R, G, B) spread over a 128x128 cell map from sources
the players place by hand. No turns and no AI: the map runs continuously and every rule is
adjustable while it runs.

## cell model

- one grid, three channels: `Uint16Array(16384)` per channel plus one back buffer per channel.
- values are fixed point: display 0..255 stored `<< 4`. Math stays integer, no floats in the
  frame path, and a cell can hold 1/16 of a display unit.
- sources: `Uint8Array(16384)`, 0 = none, 1..3 = channel + 1.
- the map is a torus: all four neighbours wrap at the edges, so the kernel has no edge case.

## rules

| setting | default | meaning |
| --- | --- | --- |
| deplete | 1 | display units lost per frame by every cell, per channel |
| diffuse | 128 | share of a cell's amount given to one neighbour, in 1/255 units |
| crossDiffuse | false | when off, a color cannot flow into a cell held by another color |
| diffuseOther | 64 | rate used when flowing into a cell held by another color |
| react | 8 | per frame, two colors in one cell both lose `min(a, b, react)` |
| speed | 4 | sim steps per rendered frame |

Per-neighbour transfer is `(v * rate) >> 10`: `>> 8` turns the rate into a share, `>> 2` splits it
between the four neighbours. rate 255 empties a cell completely in one frame, which is also the
stability limit of an explicit step.

## step order: decay, spread, sources, reaction, count

- **decay then spread**, and spread uses the post-decay value. Then `moved <= base`, a cell never
  needs a clamp to 0, and the pass becomes independent of the order cells are visited.
- **occupancy for the cross rule is sampled from the previous frame.** At a frontier both colors
  may therefore claim the same empty cell in the same frame. That is the only way cells mix while
  crossDiffuse is off, and it is what makes the reaction visible with default settings.
- **sources are pinned after spread and before reaction**, so a besieged source flickers while it
  burns the intruder instead of sitting at a constant 255.
- counting runs last, over the final state: a cell belongs to its strongest channel, cells held by
  two or more channels are reported as contested.

## tuning law

The territory of one source settles at roughly `diffuse / deplete` cells, radius
`sqrt(diffuse / (pi * deplete))`: each occupied cell loses `deplete` per frame while the source
injects `diffuse` per frame. Measured 89 cells, radius 5.3 at 128/1. Depletion 0 removes the decay
term entirely: colors then flood the map and the front is decided by source density alone.

## cost

0.26 ms per step for 16384 cells x 3 channels, 1.05 ms per frame at speed 4 — about 6% of a
60 fps frame budget, measured by experiments/sim_smoke.js.

## files

sim.js owns the grid, the rules and their settings. render.js owns canvas pixels and the pointer
to cell mapping. input.js owns painting and keys. ui.js owns the control panel and the readout.
main.js owns `$`, the boot tail and the frame loop. index.html holds markup, style and load order.

## controls

Drag on the map to place a source of the selected color, shift-drag or right-drag to erase.
1 2 3 pick a color, 0 selects erase, space pauses, s single steps, c clears the map.
