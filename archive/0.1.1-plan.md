# plan 0.1.1 — per-color cross diffusion

Per-player, per-target cross-diffusion rules and order-independent saturation/reaction fixes on top
of the 0.1.0 diffusion territory prototype.

## cross-diffusion rules

Each player `c` (R, G, B) configures two controls for each target color `t != c`:

- `crossAllow[c][t]` (boolean, default `false`): whether player `c` allows diffusion with target `t`.
- `crossRate[c][t]` (0..255 integer, default `64`): transfer rate used when `c` diffuses into a
  neighbour holding `t`.

When channel `c` evaluates a neighbour `j` containing other channel(s):

- Permission per present other color `t` is symmetric: `can(c, t) = crossAllow[c][t] || crossAllow[t][c]`.
  If either player allows, both diffuse into cells holding the other color.
- If neighbour `j` holds any disallowed other color, `c` does not enter `j`.
- If neighbour `j` holds one allowed other color `t`, `c` uses `crossRate[c][t]`.
- If neighbour `j` holds both other colors `c1` and `c2` and both are allowed, `c` uses
  `min(crossRate[c][c1], crossRate[c][c2])` so channel order never introduces bias.

## saturation and 3-way reaction order independence

- `spreadPass` accumulates `next[j] += share` without clamping inside the loop (`Uint16Array` max
  65535 safely holds the peak intermediate 8144). `sourcePass` clamps all three channels to `MAXV`
  after spread completes and before pinning sources.
- `reactPass` applies simultaneous pairwise deltas when all three channels are `>=` their paired
  demands. When at least one channel is bottlenecked (`< 2 * rate`), it drains `s = min(vr, vg, vb)`
  from all three channels first and reacts the remaining pair up to `rate - (s >> 1)`.

## controls

Under `cross diffusion (either allows -> both)`, each of the 6 ordered pairs (`R->G`, `R->B`,
`G->R`, `G->B`, `B->R`, `B->G`) has an allow checkbox and a 0..255 rate slider. Each rate slider
is disabled when neither player in that pair allows cross diffusion (`!(allow[c][t] || allow[t][c])`),
and both sliders in the pair unlock whenever either checkbox is checked.

## manual pass list

1. Open `index.html` in a browser, place R, G, B sources near each other; verify frontiers stop at
   boundaries with all 6 cross checkboxes unchecked.
2. Check only `R -> G`; verify both `R -> G` and `G -> R` sliders unlock while `B` sliders remain
   disabled, and only R and G penetrate each other while B stays blocked.
3. Set `R -> G` rate higher than `G -> R` rate with reaction at 0 and at 8; verify R pushes deeper
   into G territory than G into R.
4. Pause (`space`), paint a source on empty cells, and confirm readout updates without stepping.
