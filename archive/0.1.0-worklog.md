# 0.1.0 worklog

## 0.1.0 prototype (plan 0.1)

changed: new sim.js (grid, rules, settings), render.js (canvas, hit test), input.js (painting,
keys), ui.js (panel, readout), main.js (boot, frame loop), index.html (markup, style, load order).
new experiments/sim_smoke.js (rule measurements) and experiments/dom_smoke.js (wiring, stub DOM).
draft.txt: 128x128 map, 3 players, adjustable depletion default 1/255 per frame, cross diffusion
switch, reaction that removes both mixed colors.

validation: node --check on all five page files. sim_smoke: spread 89 cells radius 5.32, timing
0.26 ms/step and 1.05 ms/frame at speed 4, conserve drift=0 over 300 steps, mirror mismatch 0,
front cross=true reaction=0 mixed=15 total=61106 vs reaction=8 mixed=0 total=53700. dom_smoke:
5 scripts, 20 ids, paint/brush/keys/settings/clear all pass.

decisions: fixed point 4 fraction bits — integer shares truncated to 0 and frontiers froze without
them. decay before spread, spreading the post-decay value — kills the clamp and the visit-order
bias. sources pinned before reaction — a besieged source flickers instead of holding 255.
diffuseOther default 64: half of diffuse, the lowest value whose front stays visible when the
reaction is dialled down. speed 4 steps/frame: one step relaxes a blob in ~600 frames, which read
as slow at 60 fps.

pitfalls: the double-buffer swap aliased both buffers, so diffusion ran in place for the whole
prototype until a symmetry probe caught it. findings has the full note; the mirror case in
sim_smoke is the guard.

next step: let a source be placed with a strength or a radius, so a player can invest in one
border instead of dragging dozens of single cells — the map is 128x128 and a source holds only
~89 cells.
