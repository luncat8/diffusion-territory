# 0.4.3 — global simulation pace

The simulation starts at `0.125×` (7.5 ticks per real second) so players have eight times as long to react. **Simulation speed** is the first slider in the controls panel; it runs from `0.125×` to `1×` in eighths. At `1×` the simulation runs at its nominal 60 ticks per second.

## clock and rules

- `Settings.simSpeed` scales the real time entering the fixed-step accumulator. A tick still runs the same complete update: rival sources, gas, reactions, depletion, production and objective sampling. At equal tick counts the rules and hold requirements are the same at every pace.
- Rendering, input and HUD refresh keep their real-time cadence. The loop retains fractional tick time but caps work at two ticks per animation frame without storing excess work. Gaps over 250 ms contribute at most one nominal frame of real time before scaling.
- Changing speed takes effect without restarting the attempt. Pausing adds no tick time; **step** advances one full tick regardless of speed. Resetting the map clears pending tick time.
- The HUD labels objective seconds as `sim s`. A simulation second takes eight real seconds at the default pace; changing speed does not change the selected target or the progress already earned.

## settings lifecycle

- Simulation speed is global, not a scene rule. Changing scenes or generating a new task keeps the selected pace. **Reset GUI** restores `0.125×`.
- The settings serializer saves non-default values as `dt.simSpeed`, validates the slider range and step on reload, and omits the default. File URLs store the same setting in the hash.

## validation

- DOM smoke drives the loop with controlled timestamps: the same 136 ms advances one tick at the default and eight at `1×`, with the objective clock matching the tick count. It also checks the frame cap, long gaps, pause/single-step, reset, URL round trips and task changes.
- Manual pass: generate a rival task at `0.125×`, paint and adjust controls during the opening, switch to `1×` and back without losing progress, then reload the shared URL and verify the selected pace.
