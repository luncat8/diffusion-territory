# 0.2.0 — staggered gas dynamics territory

128×128 grid, three players (R, G, B) modeled as compressible gases with selectable unmixable vs mixable physics.
Unmixable gases push against each other via shared total gas pressure along a sharp VOF boundary;
mixable gases penetrate foreign territory at `mixRate`, react where overlapping, and form steady gradients under depletion
or equalize across reachable space when `depletion == 0` and `reaction == 0`.

Open `index.html` directly (`file://`), or serve the root folder. No build, no modules.

## model

Planar Q12.12 fixed-point `Int32Array` channels (`Field.ch[0..2]` over `Field.v`, `FP = 12`, `1 display unit = 4096`).
Staggered MAC face momenta and sub-quantum edge error accumulators live in `Float64Array` (`Gas.bx/by` for unmixable total pressure, `Gas.sx/sy` for mixable partial pressures).

Per frame (`Tick.run`):

1. `Field.analyze()` + `Field.caps()` — compute dominant species (`dom`), owned counts, totals, and per-cell ceilings.
2. `Gas.step(s)` (up to `2` substeps) — accelerate face fluxes (`j = damp * j + k * dp`), normalize donor outflows (`outScale`) so no cell goes negative, quantize integer edge transfers with `Float64` error accumulators (`| 0`), and enforce optional per-cell ceilings (`cap[c]`).
3. `Gas.react(s)` (only when `mixable && mixRate > 0`) — consume `floor(min_present * reaction / 100)` across mixed colors.
4. `Gas.deplete(s)` — subtract `round(depletion * FP_ONE)` from every cell (`>= 0`).
5. `Field.analyze()` + `Field.caps()` + `Source.inject(s)` + `Field.analyze()` — replenish sources up to `cap` / `budget` so sources hold peak pressure (`255` default) while keeping `owned` and `total` current.

## gas speed and stability

`gasSpeed` (`0..100`) and `gasDamping` (`0..100`) map to:

- `damp = 0.96 - 0.61 * (gasDamping / 100)^1.45`
- `k = min(0.85 * (1 + damp) / 4, (gasSpeed / 100) * 0.34)`

At default (`gasSpeed = 65, gasDamping = 15`), wave propagation speed `sqrt(k) ≈ 0.47` cells/frame (`~28` cells/s at 60 Hz) creates visible expanding waves across the 128×128 grid without instantaneous teleportation or stalling.

## unmixable vs mixable transport

- **Unmixable (`!mixable || !mixRate`)**: Shared bulk flux `(bx, by)` accelerates on total pressure `ptot = R + G + B`, routes donor species preferring the receiver's species (`sendEdge`), and runs VOF sharpening (`sharpen` + `smoothInterface`) to pull isolated `<= 1`-neighbor droplets back to the main interface while preserving exact mass and local pressure.
- **Mixable (`mixable && mixRate > 0`)**: Independent per-species fluxes `(sx[c], sy[c])` accelerate on `ch[c]` pressure differences, scaling cross-boundary flux entering foreign-held cells (`dom !== NO_COLOR && dom !== c`) by `mixRate / 100`.

## files

## validation

- `node experiments/checks.js` — 20 checks: exact unmixable/mixable mass conservation, zero-speed no-op, speed ordering, low-gradient equalization, territory caps, symmetric wall hold, high-pressure push, uniform fill (`depletion = 0`), gradient formation (`depletion > 0`), mix rate ordering, reaction vs unmixable isolation, visual 1s speed, substep clamp.
- `node experiments/dom-smoke.js` — 16 checks: boot, 10 sliders, `mixable` checkbox, R/G/B pickers, paint/erase, tooltip readout, reset, rAF loop.
- `node experiments/gas-bench.js` — timing (`~1.2–1.9 ms/frame` at 128×128) and convergence metrics.
- `node experiments/snapshot.js` — visual PNG inspection in `out/`.

Manual pass: open `index.html`; observe expanding colored waves colliding cleanly as unmixable territories; move `Depletion` to `0.5` and watch radial gradients settle around sources; return `Depletion` to `0` and watch pressure equalize; toggle `Mixable gases` and `Mix reaction` to watch colored overlaps and reactive fronts.
